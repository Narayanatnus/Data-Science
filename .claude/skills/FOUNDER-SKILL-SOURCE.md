# founder-skill (vendored)

The `founder-*` skills in this folder are copied from
https://github.com/Jakeschincariol/founder-skill (MIT License, see
`FOUNDER-SKILL-LICENSE`), commit `fd9385b0cfe1b96bebce3898fbd506d73eff5a9d`.

They are vendored here because Claude Code cloud sessions do not install
plugins enabled through `.claude/settings.json`; project skills in
`.claude/skills/` load directly from the repository.

To update: re-copy `skills/founder-*` from the upstream repo and update the
commit hash above.
